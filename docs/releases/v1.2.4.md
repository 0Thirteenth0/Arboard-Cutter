# Artboard Cutter 1.2.4

Windows x64 release adding fast, lossless raster PDF panels for oversized TIFF artwork.

## Download

- **Recommended:** `ArtboardCutter-1.2.4-Setup.exe`
- **Standalone:** `ArtboardCutter.exe`
- Verify downloads against `SHA256SUMS.txt`.

Both executables remain intentionally unsigned.

## Added

- Renamed the visible fast PDF option to **Lossless PDF**. Existing saved presets and jobs remain compatible.
- Oversized 8-bit strip-based TIFFs now export directly into PDF panels without DPI rendering, resampling, or color conversion.
- Original RGB, CMYK, or grayscale pixel samples and embedded TIFF ICC profiles are retained.
- TIFF strips are read once in bounded blocks while all panel PDFs are written, keeping memory use bounded and avoiding full-image duplication in every panel.

## Improved

- Repeated previews of the same oversized TIFF skip the failed MuPDF compatibility probe after import.
- A supplied 1.42 GB CMYK TIFF exported into two verified lossless PDFs in about 7 seconds; the supplied LZW `POSTER-6.tif` completed in about 9 seconds on the development machine.

## Limits

Tiled, planar-separate, higher-bit-depth, rotated-orientation, or very large compressed single-strip TIFFs still need to be flattened to an 8-bit contiguous strip-based TIFF. Printer/RIP proofing remains recommended for production output.
