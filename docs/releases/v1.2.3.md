# Artboard Cutter 1.2.3

Windows x64 hotfix for oversized LZW TIFF previews.

## Download

- **Recommended:** `ArtboardCutter-1.2.3-Setup.exe`
- **Standalone:** `ArtboardCutter.exe`
- Verify downloads against `SHA256SUMS.txt`.

Both executables remain intentionally unsigned.

## Fixed

- Restored live-preview rendering for oversized LZW-compressed TIFF artwork in the packaged application.
- Bundled the Imagecodecs LZW module used by the existing bounded TIFF decoder.

The source decoder already handled the supplied POSTER-4 and POSTER-6 files; this
release corrects the Windows package so it contains the same runtime codec.
