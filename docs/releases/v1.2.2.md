# Artboard Cutter 1.2.2

Patch release for very large layered TIFF artwork on Windows x64.

## Download

- **Recommended:** `ArtboardCutter-1.2.2-Setup.exe` installs the app, shortcuts,
  license notices, and the `.artboard-job` file association. Administrator permission is required.
- **Standalone:** `ArtboardCutter.exe` runs without a separate Python installation.
  Download and extract `ArtboardCutter-1.2.2-Licenses.zip` beside it for the notices.
- Verify downloads against `SHA256SUMS.txt`.

Both executables remain intentionally **unsigned**. Windows may show an
unknown-publisher or SmartScreen warning.

## Fixed

- Load and preview valid layered TIFF artwork that exceeds PyMuPDF's image-page limit.
- Read the saved TIFF composite in bounded strips, avoiding a full uncompressed source image in memory.
- Export supported oversized TIFF inputs through Raster PDF, JPG, and TIFF modes.
- Preserve the source TIFF's tagged physical dimensions and CMYK composite data.

## Compatibility

The fallback supports 8-bit, contiguous strip-based TIFF images. Oversized tiled,
planar-separate, and higher-bit-depth TIFF files still need flattening to a supported
8-bit strip-based TIFF. PDF Preserve is unavailable when the fallback is required;
select Raster mode. Embedded Photoshop layers are not made editable—the saved composite is used.

## Verification and license

The supplied 12,283 x 23,799 CMYK/LZW layered TIFF imported at its tagged 150 DPI,
rendered a nonblank preview, and produced readable CMYK JPG and TIFF proof exports.
All 123 automated Windows tests and the packaged self-test pass.
